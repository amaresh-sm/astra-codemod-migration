# Upstream provenance

This codebase is a source snapshot of `facebook/jscodeshift` at commit
`e71f63dba4f60e39944f5ef1e74a36fbdd317e1e` (release `17.4.0`). The snapshot is kept under the
standard task `codebase/` directory without its Git metadata or installed dependencies. The
production source and public documentation are retained for the migration; upstream unit tests
and fixtures are omitted from the candidate package. The separate website package is not part of
the runtime being migrated.
