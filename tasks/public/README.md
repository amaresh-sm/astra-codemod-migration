# Candidate package

This package contains a pinned source snapshot of the jscodeshift codemod toolkit and its public
compatibility materials. Implement the requested migration using this codebase; do not assume
network access or a separately installed jscodeshift package.

The public inputs include the upstream source, tests, fixtures, and the migration contract. The
snapshot provenance and test notes are in `codebase/UPSTREAM.md` and `codebase/TESTING.md`.
Additional verification tests are maintained privately by the task harness.
