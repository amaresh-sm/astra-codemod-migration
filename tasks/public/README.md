# Candidate package

This package contains a pinned source snapshot of the jscodeshift codemod toolkit and its public
compatibility materials. Implement the requested migration using this codebase; do not assume
network access or a separately installed jscodeshift package.

The public inputs include the upstream production source, API documentation, and migration
contract. Upstream unit tests and fixtures are intentionally excluded; additional compatibility
checks are maintained privately by the task harness.
