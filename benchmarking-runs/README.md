# Benchmarking run evidence

This directory stores scored-run metadata and sanitized evidence for the migration benchmark. The authoritative score registry is the repository root `scores.json`; each exported score was checked against the newest `reports/score.json` in its source artifact. Candidate source trees, dependencies, caches, and credentials are intentionally excluded. Missing Pi/OpenHands captures are represented honestly with `capture: not_captured` placeholders.

Exported runs: 71
